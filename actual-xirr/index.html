XIRR (money-weighted return)

Enter Current portfolio value in settings (from the Holdings/Valuation report) to compute XIRR. Without it, only realized cashflows are known.
Pre-tax XIRR uses external bank cashflows (invested = outflow, redemptions + current value = inflow), with STP/Switch excluded as internal. Post-tax XIRR deducts the computed tax from the terminal value. Dates parsed as DD/MM or M/D/YY with disambiguation.
